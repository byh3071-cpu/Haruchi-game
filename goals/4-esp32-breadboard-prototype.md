# Goal 4: ESP32 브레드보드 프로토타입 (납땜 제로)

## 배경

## 동작
- 부품 선정·구매 (ESP32 DevKit, I2C OLED/LCD, 택트 버튼 3개, 브레드보드)

- 버튼 입력 → 밥/물/쓰다듬기 액션 → 화면 표정 변화 동작

- 버튼 3개 액션 모두 동작
