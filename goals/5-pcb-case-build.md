# Goal 5: PCB + 3D 케이스 실물화

## 배경
실물 다마고치 최종 단계. 브레드보드 프로토타입을 PCB와 케이스로 제품화.

## 동작
- KiCad 회로도·PCB 설계 → JLCPCB 발주 (SMD는 PCBA 옵션 검토)
- 케이스 3D 모델링 (Fusion 360) → 3D 프린터 출력
- 핀헤더·스루홀 납땜, LiPo + TP4056 보호회로 전원 연결

## Completion Check
- 조립 완료된 실물에서 게임 구동
- 배터리 단독 구동 확인
