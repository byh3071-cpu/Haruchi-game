Gate 0-B 비교: 합성(A) vs 분리(B)

실제 하루치 에셋 없이도 움직임 방식 차이를 눈으로 확인하는 도구입니다. Live Server 또는 브라우저에서 이 파일을 직접 엽니다.

A. 합성 8프레임 v1 권장

픽셀 선명도 확인: 줌 4× 권장
방식: 햄스터+바퀴를 한 장 시트에 8칸 그림 → CSS steps(8)
  • 정렬 포인트 1개 (오버레이 위치만 맞추면 됨)
  • 바퀴 림은 프레임마다 같이 그려 고정 → 회전감은 다리로 표현
  • 실패 증상: 바퀴가 미끄러지듯 보일 수 있음 (대부분 수용 가능)

B. 분리 (바퀴 rotate + 다리 시트) v2 후보

회전축·햄스터 위치 어긋남 주의
방식: 바퀴 1장 + 햄스터 다리 8프레임 → 바퀴는 rotate, 다리는 steps
  • 정렬 포인트 2개 (회전축 + 햄스터 앵커) — 난이도 높음
  • 바퀴가 진짜로 돌아가서 가장 자연스러움
  • 실패 증상: 바퀴·햄스터 어긋남, 서브픽셀 흐림, 이중 바퀴
판단 가이드: A에서 “다리만 움직이고 바퀴는 고정”이 거슬리지 않으면 → v1 = A (합성)으로 구현·출시. B가 확실히 더 낫다고 느껴질 때만 v2로 분리 방식 검토. 결정 후 docs/planning/wheel-gate0-asset.md Gate 0-B에 체크하세요.
